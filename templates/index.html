          How it works

          1. Add your CV. Upload a text-based PDF or paste the text.
          2. Paste the job description. Include the requirements section for the best result.
          3. Get the analysis. Skills, experience and key requirements are extracted from both texts and compared.
          4. Edit and apply. Work through the suggested edits, then send a stronger CV.

          Privacy

          Your CV and the job description are sent to this app's server for analysis. The server does not save them: they exist in memory only while the request runs. When AI analysis is on, the server forwards the text to OpenRouter and the model provider to produce the report. Without an AI key, the basic analysis runs on the server and nothing leaves it.

          Do not include sensitive numbers such as ID or bank details in the text you submit.

          ResumeFit. Estimates are guidance, not a guarantee of any hiring outcome.
